# Normalize Shadow Dom

```ts
export function normalize(template: HTMLTemplateElement, inject: Set<string>): void {}
```

Before:

```html
<dialog aria-labelledby="label" open>
  <div id="header">
    <h2 id="label">
      <slot name="label"><span id="sr-label"></span></slot>
    </h2>
    <slot name="close">
      <button type="button" id="close-button" aria-label="Close">✕</button>
    </slot>
  </div>
  <div id="body">
    <slot></slot>
  </div>
  <div id="footer">
    <slot name="footer"></slot>
  </div>
</dialog>
```

After:

```html
<dialog id="dialog" part="dialog tag--dialog" aria-labelledby="label" open>
  <div id="header" part="header tag--div">
    <h2 id="label" part="label tag--h2">
      <slot id="slot--label" name="label" part="slot--label tag--slot">
        <span id="sr-label" part="sr-label tag--span"></span>
      </slot>
    </h2>
    <slot id="slot--close" name="close" part="slot--close tag--slot">
      <button type="button" id="close-button" part="close-button tag--button" aria-label="Close">✕</button>
    </slot>
  </div>
  <div id="body" part="body tag--div">
    <slot id="slot--default" part="slot--default tag--slot"></slot>
  </div>
  <div id="footer" part="footer tag--div">
    <slot id="slot--footer" name="footer" part="slot--footer tag--slot"></slot>
  </div>
</dialog>
```

## Rules

1. error on <slot name="default"></slot>
2. error if any id has -- in name before the normalization
3. inject ids for slots and tags that are just once in the template like dialog
4. error if there is an element without an id
5. inject if the part is not given: part="{id} tag--{tag}"

## Slot Injection

We can inject additional slots for elements with id. So `<div id="a">content</div>` with parameter inject ["a--before",
"a--after", "a--inner", "a--replace"] would be:

```html
<slot id="slot--a--before" part="slot--a--before tag--slot" name="a--before"></slot>
<slot id="slot--a--replace" part="slot--a--replace tag--slot" name="a--replace">
  <div id="a" part="a tag--div">
    <slot id="slot--a--inner" part="slot--a--inner tag--slot" name="a--inner">content</slot>
  </div>
</slot>
<slot id="slot--a--after" part="slot--a--after tag--slot" name="a--after"></slot>
```

We even allow slot injection for other slots with autogenerated ids ['slot--a--before', 'slot--a--inner']

## Hints

- Use modern dom modification methods like `replaceWith`
- Compute tag counts before hand
- Iterate all elements once
